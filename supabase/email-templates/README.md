# Sign-in emails

Paste these into Supabase: Authentication > Emails > Templates.

| Template in Supabase | File | Subject line |
| --- | --- | --- |
| Confirm sign up | `confirm-signup.html` | Welcome to CLEAR: confirm your email |
| Magic link | `magic-link.html` | Your CLEAR sign-in code |

Sender name and address are set under Authentication > Emails > SMTP settings (use the CLEAR Gmail with an app password).
